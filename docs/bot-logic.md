# Логика бота (спека клиента, 14.08) — источник правды

Оригинал: [docs/spec/логика-бота.pdf](spec/логика-бота.pdf), продуктовый пакет — в переписке. Эта версия ЗАМЕНЯЕТ старое ТЗ по клиентским сценариям (квиз/магазин-3-гайда убираются).

## Модель

Контент организован по **сезонам** (coffee, sweet, cola…). Пользователь платит за подписку на клуб (текущий сезон) и/или за вечный доступ к архивам сезонов.

**Сущности:**
- **Сезон** — набор эпизодов+бонусов одной темы. Активен (`is_current`) или в архиве. Архив = папка Google Drive.
- **Эпизод** — бесплатный подкаст (audio_link) + теги для поиска.
- **Бонус** — PDF + голосовой разбор, выдаётся по **ключевому слову** (keyword) из эпизода. Бесплатно всем.
- **Клуб «Код Алёхиной»** — платная подписка, закрытый канал: бонусы к каждому эпизоду текущего сезона.
- **Основной продукт** — интенсив/игра, продаётся в финале сезона.

## Цены (жёстко; скидка подписчику по `is_subscribed`)

| Продукт | Новым | Подписчикам |
|---|---|---|
| Подписка на клуб (мес) | 790 ₽ | — (3 мес — 1890 ₽) |
| Вечный доступ к сезону | 299 ₽ | 179 ₽ (−40%) |
| Рабочая тетрадь сезона | 599 ₽ | 359 ₽ (−40%) |
| Пакет «Все сезоны» | 999 ₽ | 599 ₽ (−40%) |
| Интенсив (финал) | 3900 ₽ | 2730 ₽ (−30%) |

Подписка = 30 дней. Вечный доступ — ссылка на Drive, бессрочно.

## Сценарии

1. **/start** — приветствие («цифровой двойник Алёхиной»). Просит ключевое слово или слово для поиска. Кнопки: «О подписке», «Найти в архиве», «Магазин сезонов».
2. **Ключевое слово** → бонус: если слово = `keyword` в bonuses → шлёт PDF + аудио. Голосовой разбор-демо выдаётся ОДИН раз, дальше — предложение 24ч-триала клуба, затем подписка. После выдачи — оффер подписки 790.
3. **Поиск по архиву** — слово не keyword → полнотекстовый поиск по `title`/`tags` в episodes+bonuses → топ-3 с кнопками (Слушать / Получить бонус / Купить сезон) + оффер подписки.
4. **Подписка на клуб** — если не подписан: оффер 790 → ЮKassa-ссылка → после оплаты `is_subscribed=true`, `subscription_expires=+30д`, инвайт в закрытый канал, список бонусов сезона. Если подписан — статус + бонусы + магазин со скидкой.
5. **Покупка сезона (архив)** — 299/179 → после оплаты `purchased_seasons += season_id`, выдать `archive_link`. Оффер пакета «Все сезоны» 999/599.
6. **Магазин сезонов** — пакеты: один сезон 299, тетрадь 599, все сезоны 999 (−40% подписчикам).
7. **Интенсив** — в финале сезона рассылка + кнопка, 3900/2730.
8. **Проверка подписки (фон)** — при каждом запросе: если `now>expires` → `is_subscribed=false`, доступ к текущему сезону блок, `purchased_seasons` сохраняются.

## БД (таблицы)

- **users**: user_id (tg), username, is_subscribed, subscription_expires, purchased_seasons[], registered_at.
- **seasons**: season_id, title, description, price, price_subscriber, archive_link, is_current, start_date, end_date.
- **episodes**: episode_id, season_id, title, audio_link, tags[].
- **bonuses**: bonus_id, season_id, keyword, title, pdf_link, audio_link, tags[], is_free.
- **main_products**: product_id, season_id, title, description, price, price_subscriber, payment_link, is_active.

## Технические

- aiogram, все кнопки Inline.
- Оплата: **ЮKassa external checkout** (create payment → confirmation_url → webhook по payment_id → обновить is_subscribed/purchased_seasons). Вебхук проверяет подпись/статус.
- Файлы (PDF/аудио) — на Google Drive, прямые ссылки.
- Рассылки по расписанию (cron): сезон кончается (−3 дня) → предупреждение подписчикам; подписка истекла → уведомление; финал → анонс интенсива.
- Логирование действий (запросы/оплаты/выдачи).

## Что переиспользуем из готового

ЮKassa create_payment, подписки/инвайт в закрытый канал, планировщик, PDF/аудио-пайплайн, Sheets/Notion/RSS, деплой (docker/caddy), fontconfig-шрифты PDF.

## Фазы

- **Фаза 1 (ядро):** новая БД; /start; бонус по ключевому слову (+демо); подписка 790 (ЮKassa+webhook); покупка сезона (архив-ссылка).
- **Фаза 2:** поиск по тегам; пакеты (все сезоны/тетрадь); интенсив; рассылки по расписанию.
