# Гайд владельца — как пользоваться ботом

Рабочий цикл на эпизод: сначала присылаете **текст** (бот собирает PDF-гайд), потом **аудио** (бот собирает готовый подкаст). Оба — боту в личку.

## PDF-гайд из текста

1. Пришлите боту **текст гайда** обычным сообщением. **Первая строка — заголовок**, остальное — тело.
2. Бот сверстает текст в фирменный PDF (логотип, цвета, шрифт) и пришлёт файл.

Контент бот не пишет и не меняет — только оформляет ваш текст по шаблону.

## Готовый подкаст из аудио

1. Запишите эпизод и пришлите **сырое аудио** боту в личку (голосовое или файл).
2. Бот предложит выбрать **фоновый эмбиент** — нажмите нужный (или «Без фона»).
3. Бот наложит фон под голос (с приглушением под речь), нормализует громкость и пришлёт готовый mp3.

Музыку присылать не нужно — фоновые подложки встроены в бота.

Команда **`/ambients`** — показывает список фонов и даёт послушать каждый (бот пришлёт трек). Текущий фон: JAGA (авторский). Остальные подложки отключены (лежат в `media/assets/ambient/_disabled/`) — при желании вернуть, перенести файл обратно в `media/assets/ambient/`.

Добавить/заменить фоны просто: положить аудиофайлы в `media/assets/ambient/` — бот подхватит их сам (имя файла станет названием). Красивое название можно задать в `media/ambient.py`.

### Про большие файлы

Обычный Telegram-бот принимает файлы **до 20 МБ**. Длинный эпизод (30+ минут) может быть больше — тогда на сервере поднимается локальный Bot API server (лимит 2 ГБ), это делается на этапе деплоя. Короткие выпуски и тесты работают сразу.

## Настройка таблиц и Notion (разово, команды в боте)

Только для владельца (ваш Telegram ID в белом списке):

- `/setup_sheets` — бот создаёт 4 листа с заголовками в вашей Google-таблице.
- `/setup_notion <id_страницы>` — бот создаёт базу «Эпизоды» на указанной странице Notion и вернёт её id (его нужно вписать в настройки).
- `/sync_notion` — вручную подтянуть эпизоды и бонусы из Notion сейчас (иначе синхронизация идёт автоматически каждые 5 минут).

## Статистика

- `/admin` — сводка за 7 дней: новые контакты, продажи, платежи.

## Наполнение контентом через Notion (основной способ)

Эпизоды и бонусы удобнее вести в Notion — бот сам переносит их в свою базу (синхронизация каждые 5 минут, либо сразу командой `/sync_notion`).

**Настройка (разово):** `/setup_notion <id_страницы>` создаёт базу «Эпизоды» со всеми нужными полями; впиши её id в `NOTION_DB_EPISODES`. Если база уже была создана раньше — проверь, что в ней есть поля «Ключевое слово», «Теги», «Название бонуса», «PDF-бонус», «Аудио-бонус» (добавь недостающие вручную или пересоздай на новой странице).

**Как заполнять карточку эпизода в Notion:**

| Поле | Что писать |
|---|---|
| Название | название эпизода (оно же заголовок бонуса, если «Название бонуса» пустое) |
| Статус | бот подтягивает только «Контент готов» и «Опубликован» |
| Сезон | код сезона — ровно как в `/add_season` (например, `sweet`) |
| Ссылка на аудио | прямая ссылка на подкаст (для поиска в архиве) |
| Теги | через запятую: `шоколад, паста, детство` (поиск по архиву) |
| Ключевое слово | слово из эпизода — по нему выдаётся бонус (например, `НУТЕЛЛА`) |
| Название бонуса | заголовок бонуса (необязательно) |
| PDF-бонус | прямая ссылка на PDF бонуса |
| Аудио-бонус | прямая ссылка на голосовой разбор |
| Пост для Telegram | текст анонса — публикуется в открытый канал при статусе «Опубликован» |

Бонус создаётся, только если заполнены «Ключевое слово» + («PDF-бонус» или «Аудио-бонус»). Эпизод для поиска — если есть «Ссылка на аудио» или «Теги». Повторная синхронизация обновляет записи (id привязан к странице Notion).

Анонсы в открытый канал идут двумя путями: авто из Podster RSS (новый выпуск) и из поля «Пост для Telegram» при статусе «Опубликован» (каждый пост публикуется один раз).

### ВКонтакте (верх воронки)

ВК — это привлечение трафика, монетизация остаётся в Телеграме. Если ВК подключён (токены в `.env`):

- В группе бот отвечает на ключевое слово — выдаёт PDF и голосовой ссылками и уводит человека в Телеграм за подпиской и клубом.
- Поле «Пост для VK» в карточке Notion при статусе «Опубликован» публикуется на стену группы (один раз).

Заполнять отдельно ничего не нужно — те же карточки Notion. Настройка доступов ВК — разово, при запуске (см. deploy-checklist).

## Сезоны, пакеты, интенсивы (командами)

Сезоны/цены/архивы меняются редко — их заводит команда (их немного). Поля через `|`:

```
/add_season    id | Название | 299 | 179 | ссылка_на_архив | 1
/add_bonus     id | season_id | КЛЮЧ | Название | pdf_ссылка | аудио_ссылка
/add_episode   id | season_id | Название | аудио_ссылка | тег1,тег2
/add_product   id | season_id | Название | 3900 | 2730 | ссылка_записи | 1
/set_workbook  season_id | ссылка_на_тетрадь
/content       — сколько всего сезонов/эпизодов/бонусов/продуктов
```

Последнее число в season/product — «активен сейчас» (1/0). Бонус выдаётся клиенту по слову из поля `КЛЮЧ`. Повторный вызов с тем же id — обновляет запись.

### Пакеты магазина и цены

- **Один сезон** — обычный сезон из `/add_season` (299 ₽, подписчику 179 ₽).
- **Рабочая тетрадь** — отдельный платный файл сезона (599 ₽ / 359 ₽). Заводится командой `/set_workbook season_id | ссылка`. Сезон появляется в разделе «Рабочая тетрадь» только когда ссылка задана.
- **Все сезоны** — служебный сезон с id `all`: `/add_season all | Все сезоны | 999 | 599 | ссылка_на_общую_папку | 0`. Покупка открывает доступ ко всем сезонам сразу. Из обычного списка сезонов он скрыт автоматически.
- Скидка 40% подписчикам применяется сама по флагу `is_subscribed`.

### Подписка и триал (автоматически)

- Клуб: **790 ₽/мес** или **1890 ₽/3 мес** — обе кнопки в «О подписке».
- Клиент после демо-голосового может забрать **24 часа** бесплатного доступа к клубу (один раз). По истечении — бот сам блокирует доступ и напоминает про подписку.
- Ничего настраивать не нужно: цены и сроки уже в конфиге. Изменить — через `.env` (`SUBSCRIPTION_PRICE`, `WORKBOOK_PRICE`, `ALL_SEASONS_PRICE` и т.д.), затем перезапуск.

Файлы (PDF/аудио/архивы) держим на Google Диске с доступом по прямой ссылке.
