# Гайд владельца — как пользоваться ботом

Рабочий цикл на эпизод: сначала присылаете **текст** (бот собирает PDF-гайд), потом **аудио** (бот собирает готовый подкаст). Оба — боту в личку.

## PDF-гайд из текста

1. Пришлите боту **текст гайда** обычным сообщением. **Первая строка — заголовок**, остальное — тело.
2. Бот сверстает текст в фирменный PDF (логотип, цвета, шрифт) и пришлёт файл.

Контент бот не пишет и не меняет — только оформляет ваш текст по шаблону.

## Готовый подкаст из аудио

1. Запишите эпизод и пришлите **сырое аудио** боту в личку (голосовое или файл).
2. Бот предложит выбрать **фоновый эмбиент** — нажмите нужный (или «Без фона»).
3. Бот наложит фон под голос (с приглушением под речь), нормализует громкость и пришлёт готовый mp3.

Музыку присылать не нужно — фоновые подложки уже встроены в бота. Список эмбиентов:

- **Нейтральный** — спокойный ровный фон.
- **Тёплый** — мягкий низкий пэд.
- **Минимал** — почти тишина, едва слышный дрон.
- **Кинематограф** — широкий минорный аккорд, для драматичных разборов.
- **Лоу-фай** — тёплый шум, ламповое звучание.

Добавить/заменить эмбиенты можно — скажите, какие настроения нужны.

### Про большие файлы

Обычный Telegram-бот принимает файлы **до 20 МБ**. Длинный эпизод (30+ минут) может быть больше — тогда на сервере поднимается локальный Bot API server (лимит 2 ГБ), это делается на этапе деплоя. Короткие выпуски и тесты работают сразу.

## Настройка таблиц и Notion (разово, команды в боте)

Только для владельца (ваш Telegram ID в белом списке):

- `/setup_sheets` — бот создаёт 4 листа с заголовками в вашей Google-таблице.
- `/setup_notion <id_страницы>` — бот создаёт базу «Эпизоды» на указанной странице Notion и вернёт её id (его нужно вписать в настройки).

## Статистика

- `/admin` — сводка за 7 дней: новые контакты, продажи, платежи.
