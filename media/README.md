# Аудио-пайплайн (ffmpeg)

Обработка **основного подкаста**: интро + голос с музыкой-подложкой (ducking) + аутро → нормализация громкости → mp3.

Аудиобонусы и голосовые разборы для закрытого канала **не обрабатываются** — сырые записи.

## Ассеты от клиента (кладём в `media/assets/`)

| Файл | Что это |
|---|---|
| `intro.*` | интро (заставка, звук микрофона в начале) |
| `outro.*` | аутро (концовка) |
| `music.*` | фоновая музыка-подложка (звучит тихо под голосом) |

Голос эпизода (сырой) присылается отдельно на каждый выпуск.

## Запуск

```bash
python -m media.pipeline --voice raw_voice.mp3 \
    --intro media/assets/intro.mp3 \
    --music media/assets/music.mp3 \
    --outro media/assets/outro.mp3 \
    -o media/out/ep01.mp3
```

Обязателен только `--voice`. Остальное опционально. Тюнинг громкости подложки: `--music-volume 0.15`.

Модуль на stdlib — работает без установки бот-зависимостей, нужен только системный `ffmpeg` в PATH.

## Профиль звука

Дефолты в `AudioProfile` (`pipeline.py`): нормализация EBU R128 `I=-16 LUFS`, подложка `volume=0.18` с ducking под голос. Правится при подгонке под первый образец клиента.
